ques1.What is the difference between synchronous and asynchronous file operations?
ans1.in synchronous The program waits until the file operation is fully completed.it executes one task at a time.
While the file is being read or written, nothing else runs.
in asynchronous File operation starts, and the program continues executing other code.in exucution it Uses callbacks, promises, or async/await.
File handling happens in the background.

ques 5.Explain the concept of piping in streams with an example.
ans 5.Piping means connecting one stream directly to another so that the output of one stream becomes the input of another stream.
example:
const fs = require("fs");

const readStream = fs.createReadStream("input.txt");
const writeStream = fs.createWriteStream("output.txt");

readStream.pipe(writeStream);
